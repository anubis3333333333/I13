## Краткое описание работы
В ходе выполнения лабораторной работы были изучены базовые концепции объектно-ориентированного программирования (ООП) на языке C#. Были освоены следующие ключевые темы:
1. Создание классов как шаблонов объектов и инициализация самих объектов (экземпляров класса) с помощью оператора `new`.
2. Объявление полей данных, создание и перегрузка конструкторов, использование ключевого слова `this` для разграничения полей класса и параметров.
3. Проектирование методов объекта с возвращаемыми значениями (`GetStatus()`) и без них (`void`).
4. Применение принципа инкапсуляции: сокрытие данных с помощью модификатора доступа `private` и организация контролируемого доступа через защищённые паттерны геттеров и сеттеров с валидацией входных значений.

В качестве практической модели была разработана базовая часть сквозного проекта «Менеджер задач» (консольное приложение `TaskMenager`).

## Примеры кода
Ниже приведена реализация класса `TaskItem` на языке C#, демонстрирующая скрытые приватные поля, конструктор с `this` и безопасные методы доступа (геттеры и сеттеры с валидацией):

```csharp


class TaskItem {
    // Приватные поля (инкапсуляция данных)
    private string title;
    private string description;
    private bool isCompleted;

    // Конструктор класса
    public TaskItem(string title, string description) {
        this.title = title;
        this.description = description;
        this.isCompleted = false;
    }

    // Геттеры для безопасного чтения
    public string GetTitle() {
        return title;
    }

    public string GetDescription() {
        return description;
    }

    public bool GetIsCompleted() {
        return isCompleted;
    }

    // Сеттер для заголовка с проверкой на пустую строку
    public void SetTitle(string value) {
        if (value == null || value.Trim() == "") {
            Console.WriteLine("Ошибка: заголовок не может быть пустым.");
            return;
        }
        title = value;
    }

    // Сеттер для описания с проверкой на null
    public void SetDescription(string value) {
        if (value == null) {
            Console.WriteLine("Ошибка: описание не может быть null.");
            return;
        }
        description = value;
    }

    // Методы изменения состояния задачи
    public void Complete() {
        isCompleted = true;
        Console.WriteLine(\$"Задача \"{title}\" отмечена как выполненная.");
    }

    public void Reset() {
        isCompleted = false;
        Console.WriteLine(\$"Задача \"{title}\" сброшена.");
    }

    // Вывод информации в консоль
    public void PrintInfo() {
        string status = isCompleted ? "+ Выполнена" : "- Не выполнена";
        Console.WriteLine(\$"[{status}] {title}");
        Console.WriteLine(\$"Описание: {description}");
    }
}
```

## Главные выводы
1. **Разделение сущностей (Класс vs Объект):** Класс является абстрактным чертежом или типом данных, который не занимает памяти во время компиляции. Объект — это конкретный экземпляр в памяти, обладающий собственным независимым состоянием. Изменение полей одного объекта никак не влияет на данные другого.
2. **Важность инкапсуляции:** Оставление полей класса открытыми (`public`) несёт огромные риски перевода объекта в некорректное или «сломанное» состояние (например, присвоение `null` или пустых строк). Сокрытие полей делает код стабильным и устойчивым к ошибкам.
3. **Контроль через геттеры и сеттеры:** Модификатор `private` защищает данные от прямого вмешательства, а геттеры и сеттеры создают контролируемый шлюз. Сеттеры выступают в роли «охранников», позволяя валидировать (проверять) входящую информацию с помощью встроенных методов (таких как `Trim()`) перед её сохранением.
